# KT Template Online Web

组件与图表模板的前台入口，提供检索、分类与 Playground 跳转。

## 本地使用

按 package.json 的版本约束选择 Node/pnpm，在 Windows 工作区运行：

```powershell
pnpm install
pnpm dev
```

开发端口为 48089；后端接入及 Playground 地址由项目公开配置指定。

## 验证与文档

```powershell
pnpm build
```

按修改选择类型、构建或已有页面测试，发布须另满足授权与在线验收。公开前端环境配置可跟踪，真实凭据不进入客户端。

[中央项目文档](../../docs/projects/web/index.md) 集中维护说明与历史资料。
